# 04. UI 신뢰 규칙 (모르는 값·실패·읽기 전용)

AI·모니터링 화면은 **틀린 값보다 "모른다"가 낫다.** DejaFix가 화면에서 지킨 규칙이고, 같은 종류의 다음 프로젝트에도 그대로 쓸 수 있다. 코드는 팀 CLAUDE.md의 안전 항목(SAFE-xx)에서 온 것이며 번호는 DejaFix 문서 기준이다.

## 1. 값 표시

| 규칙 | 구현 | 근거 |
|---|---|---|
| 값이 없으면 **0·빈칸·`NaN`·"null"로 그리지 않는다.** `Unknown`(확인할 수 없음 · 사유 · 수집 시각)으로 | `IncidentParts.Unknown`, `Chips.UnknownValue` | SAFE-10 |
| 서버가 주는 숫자는 `Measured`(`value`, `unit`, `collected_at`, `unknown`, `unknown_reason`). `unknown`이거나 `value`가 `null`이면 `Unknown` | KPI 카드 | SAFE-10 |
| 고정 숫자를 화면에 박아 두지 않는다(메뉴 배지·KPI·"N일째" 힌트). 못 받았거나 갱신에 실패했으면 **숨기거나 "확인할 수 없음"** | `Layout`의 배지(`openCount`), KPI | SAFE-08·09 |
| 확신도는 **낮음/보통/높음** 문자만. 퍼센트·점수 금지 | `ConfidenceChip` | SAFE-11 |
| 사유 코드는 5종만: `NO_DATA`, `STALE`, `TOOL_ERROR`, `NO_PERMISSION`, `NOT_COLLECTED` | `UnknownReason` | 계약 |

## 2. 실패·오래된 값

- 실시간 값 조회가 실패하는 동안은 **마지막 성공 값을 현재처럼 보이지 않는다**(`hideDataOnError`). 연결 상태를 못 받으면 칩 대신 "연결 상태 확인할 수 없음".
- 연결이 끊기면(예: 모니터링 서버 `down`) **15초 폴링 안에** 경고 배너(`role="alert"`)를 띄우고 "실시간 값은 확인할 수 없고 저장된 것만 볼 수 있다"고 알린다.
- 저장 데이터(장애 목록)는 마지막 값을 유지하되 갱신 실패를 같이 표시한다.
- 데이터가 오래되면(수집 5분 지연 등) 정상처럼 두지 않고 "지연"으로 올린다(`SystemList`).

## 3. 읽기 전용·실행 금지 UI

- **라벨이 "실행·Run·Execute"인 `button`·`a`·`input`을 만들지 않는다.** 실행 토글·승인 워크플로 UI도 없다. 변경은 **계획 미리보기**까지만 보여 준다.
- 조치 등급은 색·라벨로 구분한다: A 초록 "조회 · 안전", B 주황 "변경 · 승인 필요(미구현)", C 빨강 "금지 · 사람이 판단". 각 단계에 **사전 확인·예상 효과·위험·롤백**을 같이 보여 준다.
- 화면은 **표시만** 한다. 서버가 만든 분석 문장·원인 순위·등급을 화면에서 계산하거나 바꾸지 않는다.
- 다시 분석·메일 재발송·검토 같은 쓰기 버튼은 필수 범위가 끝나기 전에는 렌더하지 않는다.

## 4. 근거 추적

- AI가 한 말에는 **근거 ID**를 붙이고, 누르면 어떤 도구를 언제(호출 시각·데이터 시각) 어떤 인자로 호출해 무슨 결과를 얻었는지 펼쳐 보여 준다(`EvidenceIds`·`EvidencePanel`).
- 기록에 없는 근거 ID는 눌리지 않게 하고 "근거 기록 없음"으로 표시한다.
- 원인 후보에는 근거가 없으면 확신도 "낮음"으로 둔다(서버 규칙, 화면은 그대로 표시).

## 5. 보안

- JWT는 `sessionStorage`에만. 키·토큰을 번들·`localStorage`에 두지 않는다. 로그아웃 시 쿼리 캐시를 비운다.
- 브라우저는 모니터링 서버·Agent를 **직접 부르지 않는다.** 모든 요청은 상대 경로 `/api`(백엔드)로.
- 채팅 응답이 모르는 걸 물으면 "확인할 수 없음 · NOT_COLLECTED"로 답하게 하고, 화면은 지어낸 답을 채우지 않는다.
- 서버는 **IP·DNS·토큰·URL을 어떤 응답에도 넣지 않는다**(외부 LLM으로 나가지 않게). 화면도 그런 값을 새로 만들어 보여 주거나 로그·캡처에 남기지 않는다. 발표용 캡처에서도 가린다.
- "오래된 값"(수집 주기×3 또는 10분 초과)은 **서버가 판정**해 `STALE`로 보낸다. 화면은 그 판정을 그대로 표시하고, 자체 기준(예: 사이드바 수집 5분 지연)은 보조 표시일 뿐 값을 숨기거나 바꾸지 않는다.

## 6. 머지 전 수동 점검표

- [ ] DOM에 "실행/Run/Execute" 요소 0개
- [ ] `localStorage`에 토큰 없음, 번들에 키 문자열 없음
- [ ] 모든 `null`이 `Unknown`으로 나옴 (목의 `unknown:true` 경우 포함)
- [ ] 확신도에 `%` 없음
- [ ] 서버를 내리면 15초 안에 경고 배너, 값은 "확인할 수 없음"
- [ ] 네트워크 탭: 폴링 간격 15±2초, 채팅 요청에 `Authorization` 헤더
- [ ] 주소창에 상세 주소 직접 입력 → 404 아님

> 이 중 SAFE 번호·"실행 금지"·A/B/C 등급은 **DejaFix(장애 대응) 전용**이다. 일반 대시보드라면 1·2·4·5장(모르는 값, 실패 표시, 근거, 보안)만 가져가면 된다.
