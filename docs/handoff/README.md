# handoff — 로테이션 인수인계 메모 (기획서 10-3)

로테이션마다 인계자가 `docs/handoff/<MMDD>-<컴포넌트>.md`를 쓴다. 1회차는 **10/15 13:00**(DB·메일 담당 → 팀장 Agent 기술 검토 인계), 2회차는 데모 직후.

## 의무 사항
1. 이 메모 작성(아래 양식 ①~⑥)
2. 폴더 `CLAUDE.md` 최신화(인계 전 주담당이) — Claude가 다음 사람에게도 같은 맥락을 주도록
3. **30분 페어 세션**: 인계자 화면에서 받는 사람이 직접 한 번 실행·테스트
4. 진행 중 작업은 머지하거나 draft PR로. 로컬에만 있는 코드는 인계 대상이 아니다(없는 것으로 간주)
5. 계약 소유자가 바뀌면 `contracts/README.md` 소유자 표를 같은 PR에서 갱신
6. 인계자는 이후 24시간 질문에 우선 응답
7. 크리티컬 패스 작업(`docs/work-order.md` 1-3)은 블록 DoD를 채우기 전에는 인계하지 않는다
